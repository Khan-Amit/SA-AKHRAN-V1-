🛡️ Install SA-AKHRAN

Copy and paste the following commands into your terminal (Linux / macOS / Termux).

1. Clone the repository

git clone https://github.com/khan-amit/SA-AKHRAN-V1-.git cd SA-AKHRAN-V1-

2. Compile the backend filters

cd backend make cd ..

3. Run the full pipeline (test)

cat sample_data.txt | ./backend/sluice1 | ./backend/sluice2 | ./backend/sluice3 > filtered.txt

4. Open the dashboard

open frontend/index.html

For VoIP filtering, edit voip/blacklist.txt and voip/whitelist.txt, then run:

cd voip python voip_filter.py +1234567890
